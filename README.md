# 🐵 gokuu-new

## 題名

　第9条の芦田修正を論理的に解明し改憲案の策定

## 目的

　悟空サイトは、第９条を改憲するための理論と条文を考察して、静的サイトとして公開します。

　使用言語：HTML
　
　構　  成：多層的構造

　エディタ：TeraPad 
 
## 構成の概要

　**理論的根拠**   
  芦田修正を、二律背反構造の論理的解明で、その意図を明確にし、改憲案の策定を考察します。

　**必要性**   
  前文の理想と第９条の現実の乖離及び第９条が内在する問題を検証し、改憲の必要性を提示します。
  
  **構成の目的** 
1.　第１・第２項は、平和憲法の象徴として残すとともに芦田修正の目的を理論的解釈で国家防衛権の正当性を証明します。
 
２.　第３項は、第１・第２項の戦争の放棄、戦力及び交戦権の否認を全く正反対の国家防衛権行使を可能とするための加憲案を策定する立場から、第１・第２項の二律背反構造の概念を本項で規定します。

３.　第４項は、国際社会の一員として果たすべき責務を憲法上に位置づけるもので、国際平和の維持に貢献し平和主義を内向きの理念にとどめず、国際的実践へと昇華させる意義を有します。

４.　第５項は、文民統制の確保と組織運営の安定性を目的として、防衛機関を規定し戦前の統帥権独立の反省を踏まえた慎重な制度設計を志向するものであります。

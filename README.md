## 研究テーマ

日本国憲法第９条の芦田修正を論理的に解明し、改憲案を策定する研究です。

## 目的

本研究では、第９条の制定経緯、条文構造及び国際法との関係を考察し、二律背反構造の論理的解明に基づく改憲案を策定します。

使用言語：HTML

構成：多層的構造

エディタ：TeraPad（HTML編集）、Notepad++（README編集）
 
## 構成の概要

　**理論的根拠** 
  
 芦田修正を二律背反構造の論理から解明し、その意図を明らかにしたうえで、改憲案を策定します。

　**必要性**
   
 前文の理想と第９条の現実の乖離及び同条が内在する問題を検証し、改憲の必要性を提示します。

  **構成の目的** 
  
1.&#32;第１・第２項は、平和憲法の象徴として残すとともに、芦田修正の目的を理論的に解釈し、国家防衛権の正当性を証明します。

2.&#32;第３項は、第１・第２項の戦争の放棄、戦力及び交戦権の否認と対極にある国家防衛権の行使を可能とする加憲案を策定する立場から、第１・第２項の二律背反構造の概念を本項で規定します。

3.&#32;第４項は、国際社会の一員として果たすべき責務を憲法上に位置づけるもので、国際平和の維持に貢献し、平和主義を内向きの理念にとどめず、国際的実践へと昇華させる意義を有します。

4.&#32;第５項は、文民統制の確保と組織運営の安定性を図るため、憲法では「防衛機関」として設置の根拠を定め、具体的な名称や組織などは法律に委ねることにより、戦前の統帥権独立への反省を踏まえた慎重な制度設計を志向するものであります。
